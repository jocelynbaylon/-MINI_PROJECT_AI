1. Course Learning Outcomes (CLOs)

CLO #Bloom's LevelDescriptionMapped PLOs
CLO 1 Remember/Understand Explain the fundamental architecture and components of relational database management systems. PLO 1
CLO 2 Apply/Analyze Design normalized relational database schemas using ER modeling and normalization techniques. PLO 2, PLO 3
CLO 3 Apply/Analyze Construct SQL queries involving joins, subqueries, and views to retrieve and manipulate data. PLO 2
CLO 4 Apply/Analyze Implement transactions, constraints, and stored procedures to enforce data integrity. PLO 2, PLO 3
CLO 5 Evaluate/Create Design and deploy a functional database system as a capstone project for a real-world scenario. PLO 3, PLO 5
